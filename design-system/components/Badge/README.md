# Badge

A short fact attached to something else, such as a runtime, a module number or a price qualifier, on a flat field. Bold 16px sentence case, tabular figures, 32px high on one line. It wraps instead of overflowing when text is enlarged. Prefer plain text wherever the field adds nothing.

Prop: `tone`:

- `neutral`: `fg-strong` on `bg`, for a `surface` section.
- `highlight`: `highlight-fg` on `highlight`, for the one fact a reader must not miss. At most one per view.
- `dark`: `fg-on-dark` on `surface-dark`.
