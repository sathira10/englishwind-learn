# Footer

A compact close on one `surface-dark` band: the wordmark at `h2` size over the site description in `fg-on-dark-muted` (6 of 12 columns), then the follow links and contact (3 columns each), then the copyright and legal links in `small`. Course links live in the nav, not here.

Column heads are `ew-label`. Every link is a 44px `ew-link` row with no extra gap, so rows line up across columns. Brand marks are never coloured here: they take the link colour. Contact is the WhatsApp number with its mark, in tabular figures, then the email. Links underline in their own colour on hover. An "Analytics settings" link appears only when analytics are configured. It carries `data-sticky-hide`. All text comes from site data.
