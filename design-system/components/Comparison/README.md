# Comparison

Two columns as two fields of colour: the typical approach on `surface` in `fg-muted`, the Blueprint or the live class on `surface-dark` in bold `fg-on-dark`. The repeated column names on phones use `fg-on-dark-muted`, not an opacity tint. Above 640px the rows line up across; below it each row stacks its pair, with the column name repeated in each cell.

Props: `columns` (two names), `rows` (pairs of strings). Reading order is left cell then right cell in both layouts.

Not used on any page in this version; the preview rows are illustrative, built from facts in site data and the copy guide.
