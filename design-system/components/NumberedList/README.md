# NumberedList

`ew-numbered`: filled bands for short sequences that are not steps, such as the twelve weeks or the webinar agenda. `space-4` apart, `space-6` padding, no index numbers.

Items are `surface` on a white section, `bg` with `data-item-surface="page"` on a pale-blue section, and `surface-dark-alt` inside `data-surface="navy"`. This is a CSS pattern, not a component.
