# SectionHeading

The head of every band: a headline and an optional lead, with no kicker above it.

Props: `title`, `level` (1, 2 default, or 3), `size` (`display-1` | `display-2` | `h2` | `h3`, overriding the level's size), `measure` (`22ch` default or `24ch`, so the headline wraps into a block), `align` (`start` default; `center` only for a section that stands alone). The lead is the slot, `space-6` below (heading to copy).
