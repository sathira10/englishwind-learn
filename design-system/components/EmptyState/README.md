# EmptyState

App only (englishwind-learn, `src/client/components/EmptyState.tsx`). A flat `surface` panel (`ew-panel`) for a list with nothing in it. It holds an `h3`-sized heading that says what is true ("No orders waiting"), one `base` sentence and, optionally, a next step. It has no icon or illustration.

Props: `title`, `children` (the sentence), `action` (usually a Button), `headingLevel` (2 or 3, default 3). Reassure first, then offer the next step. Never scold or invent urgency.
