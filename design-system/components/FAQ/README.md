# FAQ

Questions as native `<details>`/`<summary>` items, `space-1` apart, with no JavaScript and no animation. Each question is an `h3`-size Archivo heading with a + / − marker; the answer is `body` copy at 1.7 leading within the 65ch measure.

`FAQ` props: `itemSurface` (`surface` default; `page` for a pale-blue section, so items take `bg`). `FAQItem` props: `question`; the answer is the slot. Say each reassurance once: if /help covers it, the FAQ doesn't repeat it.
