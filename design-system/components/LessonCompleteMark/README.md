# LessonCompleteMark

App only (englishwind-learn, `src/client/components/LessonCompleteMark.tsx`). Marks a lesson the student has finished. It is `ew-complete`: a 20px `check` icon and the word "Complete" in bold 16px `fg-on-dark`, on a `surface-dark` field 32px high. The word always stays; the tick adds to it.

Prop: `complete`. When it is false, nothing is drawn.
