# LessonCompleteMark

App only (`src/client/components/LessonCompleteMark.tsx`). "Complete" in bold 16px `fg-on-dark` on a `surface-dark` field, 32px high, beside a lesson the student has finished. Prop: `complete`; when false nothing is drawn.

It is words, not a tick: the design system allows no icons. Whether to add a tick upstream is OPEN-QUESTIONS Q25.
