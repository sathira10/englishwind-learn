# Interface

The interface icon set used by `Icon`: check, close, arrow-left, arrow-right, chevron-right, chevron-down, download, play, busy and sign-out. Each is a 24-unit SVG stroked in `currentColor` at weight 2, with round caps and joins and no fill. An `<img>` shows them in black, so inline them to take the text colour. Use 20px (`icon-sm`) beside a label, or 24px (`icon-md`) when the icon is the whole control. See `components/Icon/README.md` for the rules.
